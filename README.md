# 🎧 Spotify Auto-Liker

Простой Python-скрипт для **автоматического лайка** текущего трека, проигрываемого в Spotify — по горячей клавише или
автозапуску при старте системы.

> 🤖 Также в репозитории есть **Telegram-бот**, который присылает ваши любимые треки из Spotify в виде mp3 с SoundCloud —
> см. раздел [Telegram-бот](#-telegram-бот-любимые-треки--mp3). Рабочий бот: [@spoteebot](https://t.me/spoteebot).

---

## 📚 Используемые библиотеки

- [Spotipy](https://spotipy.readthedocs.io/en/2.22.1/) — официальная Python-обёртка для Spotify Web API

---

## 🔥 Что делает этот скрипт?

- Получает информацию о **текущем проигрываемом треке**
- Добавляет его в "Любимые треки" на Spotify (ставит ❤️)
- Работает **в фоне**, без лишних окон
- Можно запускать по хоткею (`Ctrl + Alt + L`) (см. далее)

# 🤖 Telegram-бот: любимые треки → mp3

**Бот в Telegram: [@spoteebot](https://t.me/spoteebot)** — доступ выдаёт администратор: напишите боту, и он отправит запрос.

Бот берёт ваши «Любимые треки» из Spotify, находит каждый трек на SoundCloud с помощью
[yt-dlp](https://github.com/yt-dlp/yt-dlp), скачивает его в mp3 и прописывает теги из Spotify:
название, исполнители, альбом, исполнитель альбома, номер трека, год и обложка.

Список треков бот получает одним из двух способов:

- **без ключей Spotify API** — вы присылаете боту выгрузку библиотеки: CSV из [Exportify](https://exportify.app)
  или `YourLibrary.json` из официальной выгрузки данных Spotify (см. [Режим без Spotify API](#режим-без-spotify-api));
- **через Spotify API** ([Spotipy](https://spotipy.readthedocs.io/)) — нужны свои ключи приложения Spotify,
  зато список всегда актуален.

## Что умеет

- `/tracks` — листать любимые треки: по **10 треков на страницу**, каждый трек — кнопка, внизу ◀️ / ▶️.
  Нажали на трек — бот скачивает его и присылает в диалог.
- `/last N` — скачать **N последних добавленных** треков (без числа — `LAST_TRACKS_DEFAULT`, по умолчанию 10).
  Треки приходят от старых к новым, в конце — сводка, что не удалось найти.
- **Поиск по названию** — просто напишите боту `Исполнитель - Название`, и он пришлёт mp3 с SoundCloud
  с этими тегами (как будто трек пришёл из CSV). Можно несколько строк — по треку на строку.
  Без тире (`daft punk get lucky`) бот ищет по всей фразе, а исполнителя и название берёт из найденного трека.
- `/import` — как загрузить выгрузку библиотеки; сам файл просто отправьте боту. `/forget` — удалить выгрузку.
- `/login`, `/logout` — подключить/отключить свой аккаунт Spotify (у каждого пользователя бота свой токен).
- `/settings` — качество mp3. Настройки общие для всех: любой пользователь может выбрать новое значение,
  а применится оно после одобрения админом.
- `/admin` — только для админа: качество mp3 и доступ к боту (см. [Админка](#админка)).
  Доступны, только если заданы ключи Spotify API.
- Повторная отправка трека мгновенная: бот запоминает `file_id` уже загруженного в Telegram файла.

## Режим без Spotify API

Ключи `SPOTIFY_CLIENT_ID` / `SPOTIFY_CLIENT_SECRET` можно не задавать — тогда не нужны ни приложение
на developer.spotify.com, ни Premium. Библиотеку бот берёт из файла, который вы ему присылаете:

| Источник | Как получить | Что внутри |
|---|---|---|
| **CSV из Exportify** (рекомендую) | [exportify.app](https://exportify.app) → войти через Spotify → у «Liked Songs» нажать Export | название, исполнители, альбом, длительность, дата релиза, обложка, **дата добавления** |
| **Выгрузка данных Spotify** | [spotify.com/account/privacy](https://www.spotify.com/account/privacy/) → «Скачать данные» → данные аккаунта; архив приходит на почту, обычно за несколько дней | название, исполнитель, альбом, ссылка на трек |

- Можно прислать весь zip-архив выгрузки Spotify — бот сам найдёт в нём `YourLibrary.json`.
  Также подойдёт CSV из похожих сервисов (TuneMyMusic, Soundiiz), если в нём есть колонки с названием и исполнителем.
- Новая выгрузка заменяет предыдущую. Выгрузка — это снимок: после новых лайков пришлите файл заново.
- Если в файле есть даты добавления (Exportify), `/last N` берёт самые свежие треки; если нет — первые N по порядку в файле.
- В выгрузке Spotify нет длительности, поэтому трек на SoundCloud подбирается только по названию и исполнителю —
  совпадения чуть менее точные. Обложку бот в этом случае берёт из публичного
  [oEmbed](https://developer.spotify.com/documentation/embeds/reference/oembed) Spotify (ключ не нужен).
- Если заданы и ключи API, и загружена выгрузка — используется выгрузка. Удалить её — `/forget`;
  успешный `/login` тоже удаляет выгрузку и переключает бота на Spotify API.

## Админка

Админ задаётся в `.env`: `ADMIN_USER_IDS=883905237` (можно несколько ID через запятую). Админ всегда имеет доступ
и управляет ботом прямо из чата:

- `/admin` — панель настроек:
  - **🎚 Качество mp3** — 128 / 192 / 256 / 320 kbps. По умолчанию — `AUDIO_QUALITY` из `.env`.
    Уже отправленные треки перекачаются в новом качестве при следующем запросе;
  - **👥 Пользователи** — кто имеет доступ; ❌ убирает пользователя, ➕ открывает выбор из контактов Telegram.
- `/allow ID [ID…]`, `/deny ID [ID…]` — открыть или закрыть доступ по Telegram ID.
- **Запросы доступа:** когда боту пишет незнакомый человек, админу приходит сообщение с кнопками
  «✅ Разрешить» / «🚫 Отклонить», и бот сообщает человеку о решении. Пока админ не ответил, повторных запросов
  нет; после отклонения новый запрос возможен через сутки. Если админ закрыл доступ, человек может запросить его снова.
- **Запросы на смену настроек:** пользователь выбирает новое значение в `/settings`, админу приходит запрос
  «✅ Применить» / «🚫 Отклонить», пользователь получает ответ. Админ в `/settings` меняет настройки сразу.

Пользователи из `ALLOWED_USER_IDS` и админы задаются только в `.env` — из бота их не убрать.
Выданный через бота доступ и выбранные настройки хранятся в `data/bot.sqlite3` и переживают перезапуск.
Если не заданы ни `ADMIN_USER_IDS`, ни `ALLOWED_USER_IDS`, ботом может пользоваться кто угодно.

Новые настройки добавляются в одном месте — список `OPTIONS` в `bot/runtime.py`; `/admin`, `/settings`
и запросы на изменение подхватят их сами.

## Как бот ищет трек

1. Запрос на SoundCloud: `<основной исполнитель> <название>` (без `feat.` и хвостов вроде `- Remastered 2011`).
2. Из результатов выбирается лучший кандидат:
   - длительность совпадает со Spotify (допуск ±6%, минимум ±7 с);
   - в названии есть слова из названия трека, плюс бонус за совпадение исполнителя;
   - отбрасываются ремиксы, каверы, live, sped up / slowed, nightcore и т.п., если это не та версия, что в Spotify.
3. 30-секундные превью (треки SoundCloud Go+) пропускаются — бот пробует следующего кандидата.
4. Если в `SEARCH_SOURCES` указано несколько источников (например, `soundcloud,youtube`), следующий используется,
   когда в предыдущем ничего не нашлось.

## Установка

Нужны **Python 3.10+** и **ffmpeg** (yt-dlp конвертирует звук в mp3 через него).

### 1. Создай бота

Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи токен.

### 2. Настрой приложение Spotify (необязательно)

Пропусти этот шаг, если будешь пользоваться ботом [без Spotify API](#режим-без-spotify-api).

Как в разделе выше: https://developer.spotify.com/dashboard → приложение → `Client ID`, `Client Secret`,
Redirect URI `http://127.0.0.1:8888/callback`.

Пока приложение в **Development mode**, Spotify пускает только пользователей из вкладки **User Management** —
добавь туда e-mail своего Spotify-аккаунта (и аккаунтов тех, кто ещё будет пользоваться ботом).
По правилам Spotify с февраля 2026 года у владельца приложения в Development mode должен быть Premium.

### 3. Заполни `.env`

```commandline
cp .env.example .env
```

Обязательна только `TELEGRAM_BOT_TOKEN`. `SPOTIFY_CLIENT_ID` и `SPOTIFY_CLIENT_SECRET` — если нужен вход через Spotify API.
Задай `ADMIN_USER_IDS` (свой Telegram ID) — тогда бот закрыт для чужих, а доступ ты выдаёшь из чата через `/admin`.
Остальные настройки описаны в [`.env.example`](.env.example).

### 4. Запусти

```commandline
pip install -r requirements.txt
python -m bot
```

или в Docker (ffmpeg уже внутри, данные — в `./data`):

```commandline
docker compose up -d --build
```

### 5. Подключи библиотеку в чате с ботом

**Без API:** отправь боту CSV из Exportify или выгрузку Spotify (zip или `YourLibrary.json`). Подсказка — `/import`.

**Через Spotify API:**

1. Отправь боту `/login` и нажми кнопку «Войти через Spotify».
2. Разреши доступ. Spotify перенаправит на `http://127.0.0.1:8888/callback?code=...` —
   страница не откроется, **это нормально**.
3. Скопируй адрес из адресной строки целиком и отправь боту. Бот обменяет код на токен
   (хранится в `data/tokens/<telegram_id>.json` и дальше обновляется сам) и удалит сообщение с кодом.

Готово: `/tracks` или `/last 20`.

## Ограничения

- Telegram не даёт ботам отправлять файлы больше **50 МБ** (для mp3 192 кбит/с это ~35 минут).
- Треки, которые на SoundCloud есть только по подписке Go+, скачать нельзя — бот напишет, что не нашёл трек.
- Сайты меняются, поэтому yt-dlp стоит регулярно обновлять: `pip install -U yt-dlp`.
  Для YouTube свежим версиям yt-dlp может понадобиться JS-рантайм (например, deno) — см. вики yt-dlp.
- Скачивай только то, что тебе разрешено скачивать.

## Структура

```
bot/
├── __main__.py     # запуск: python -m bot
├── config.py       # настройки из .env
├── spotify.py      # OAuth для каждого пользователя, любимые треки (Spotipy)
├── importer.py     # разбор выгрузок: CSV (Exportify и др.), YourLibrary.json, zip
├── query.py        # трек из сообщения «Исполнитель - Название»
├── library.py      # откуда брать треки: выгрузка или Spotify API
├── downloader.py   # поиск на SoundCloud, выбор совпадения, mp3 + теги (yt-dlp, mutagen)
├── sender.py       # отправка в Telegram, кэш file_id, защита от параллельных загрузок
├── storage.py      # SQLite: метаданные треков, file_id, импортированные библиотеки
├── keyboards.py    # кнопки: 10 треков на страницу + навигация
├── handlers.py     # команды и нажатия кнопок (aiogram 3)
├── admin.py        # /admin, /allow, /deny, запросы доступа
├── runtime.py      # настройки из /admin (качество и др.) и правила доступа
└── middlewares.py  # пускает только пользователей с доступом
```

Тесты (сеть не нужна, ffmpeg нужен для тестов тегирования):

```commandline
pip install -r requirements-dev.txt
pytest
```
